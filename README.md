# MHP – concept website (Group 2)

Concept proposal for MHP Horlogerie, prepared by Group 2 (EM Normandie) as digital marketing consultants. This is not MHP's official website.

- `index.html`: homepage concept
- `our-watches/grand-classic-atelier/grand-classic-atelier-gold-18k-yellow-gold-chronograph-watch.html`: product page concept, Grand Classic Atelier Gold (18K yellow gold)
- `media/`: images and films. Product, macro, artisan photos and films belong to MHP. Images marked as AI are mood references only.

The pages carry `noindex`, so search engines do not list them.

Live version (GitHub Pages): https://lisa453616.github.io/mhp/
